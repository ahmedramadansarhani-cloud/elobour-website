هذه اللوحة تستخدم PIN محلي في المتصفح فقط للتجربة. ليست حماية نهائية. الدخول الآمن الحقيقي يتطلب Supabase Auth (إيميل + كلمة سر مشفرة + RLS). لم يتم ربطه بعد لأن إنشاء مشروع Supabase يتطلب حسابك أنت، ولا أستطيع إنشاءه من هنا. اتبع خطوات README لربطه. لا تنشر هذه اللوحة للعامة قبل ربط Supabase Auth.

ضع PIN من اختيارك أول مرة، وبعدها ادخل بنفس PIN على نفس المتصفح.
